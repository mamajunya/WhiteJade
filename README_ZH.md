# WhiteJade - Pixiv 智能下载与审核工具

WhiteJade 是 cll 计划的主分支之一，旨在高效地从 Pixiv 精选内容。

## 功能特点

### 核心功能
- **智能搜索下载**：根据关键词、收藏数等条件批量下载 Pixiv 作品
- **收藏夹下载**：直接下载你的 Pixiv 收藏夹/书签中的作品
- **多线程下载**：可配置并发下载线程数（1-10，默认 3），大幅提升下载速度
- **并行审核**：下载和审核同时进行，互不阻塞
- **动图支持**：支持下载、审核和自动转换 Pixiv 动图
  - 自动转换为 GIF 或 MP4 格式（可在设置中配置）
  - 默认：GIF 格式
  - 智能帧采样审核
- **AI 内容审核**：使用 DeepDanbooru 深度学习模型自动过滤不适宜内容
- **自定义过滤标签**：从 16 个 NSFW 标签中选择需要过滤的内容
- **精准数量控制**：自动调整下载量，确保最终保留图片达到目标数量
- **任务控制**：支持暂停、继续、停止任务
- **主题定制**：可自定义界面主题色和背景色
- **多语言支持**：中文、日语、韩语、英语、法语、德语
- **系统托盘**：最小化到系统托盘，后台运行
- **自定义下载目录**：设置自定义下载文件夹，支持数据自动迁移
- **灵活关闭行为**：可选择退出、最小化到托盘或每次询问

### 高级筛选
- 跳过 R-18 内容
- 去除 AI 生成作品
- 跳过或仅下载动图
- 最小收藏数过滤
- 可调节审核严格度（5档）
- 自定义过滤标签选择（16 个 NSFW 标签可选）
- 调试日志用于详细审核分析

### 自动化管理
- 自动分类：合格图片、过滤图片、下载历史
- 去重机制：避免重复下载
- 详细统计：下载数、审核数、过滤率等

## 使用说明

### 1. 获取 Pixiv Token
在"Token 获取"标签页：
1. 输入 Pixiv 账号和密码
2. 点击"获取 Token"
3. 自动复制到剪贴板
4. 点击"保存到配置"

### 2. 下载与过滤
在"下载与过滤"标签页：

**下载模式**
- 关键词搜索：通过关键词搜索并下载（原有模式）
- 我的收藏夹：下载你的 Pixiv 收藏夹/书签中的作品

**下载设置**
- 搜索关键词：输入角色名或标签（仅关键词搜索模式）
- 下载数量：最终保留的图片数量
- 最小收藏：过滤低收藏作品
- 跳过 R-18：过滤成人内容
- 去除 AI 作品：过滤 AI 生成内容
- 跳过动图：跳过动画作品（ugoira）
- 只下载动图：仅下载动画作品（与跳过动图互斥）

**审核设置**
- 启用图片审核：自动过滤不适宜内容
- 检测阈值：0.4（非常严格）到 0.8（非常宽松）
  - 动图动态帧采样：0.4 时 100% 帧，0.5 时 90%，0.6 时 80%，0.7 时 60%，0.8 时 40%
  - 动图阈值偏移：-0.1（对低画质动图更严格审核）
- 高级过滤选项：自定义需要过滤的 NSFW 标签
  - 16 个可选标签包括：penis、sex、vaginal、anal、fellatio、cunnilingus、pussy、nude、masturbation、cum、orgasm、ejaculation、nipples、pussy_juice、sex_from_behind、female_ejaculation
  - 默认：penis + sex（推荐大多数用户使用）
  - 紧凑 UI：显示已选标签，点击按钮打开对话框
  - 设置在应用重启后保持
- 移动到 ban 目录：将过滤图片移动而非删除

## 审核机制

### DeepDanbooru 模型
- 专门针对动漫图片训练的深度学习模型
- 9176 个标签分类
- 自动检测并过滤不适宜内容
- 支持静态图片和动图（ugoira）审核

### 动图审核与转换
- **动态帧采样**：根据阈值严格度调整采样率
  - 0.4（非常严格）：100% 帧数
  - 0.5（严格）：90% 帧数
  - 0.6（默认）：80% 帧数
  - 0.7（宽松）：60% 帧数
  - 0.8（非常宽松）：40% 帧数
  - 均匀分布采样整个动画
- **更严格阈值**：动图审核使用阈值 - 0.1（因画质较低）
- 所有采样帧都必须通过审核，动图才会被保留
- 如果任何一帧未通过，整个动图将被过滤
- **自动转换**：审核通过的动图自动转换为 GIF 或 MP4
  - GIF：通用格式，兼容性好，文件较大
  - MP4：现代格式，文件较小，需要视频播放器
  - 可在设置标签页配置格式
  - 转换成功后删除原始 ugoira 文件（zip + 帧）
- 高效采样确保全面审核而无需处理所有帧

### 过滤标签
默认标签（推荐）：
- `penis`（男性生殖器）
- `sex`（性行为）

额外可选标签（共 16 个）：
- `vaginal`、`anal`（插入类型）
- `fellatio`、`cunnilingus`（口交行为）
- `pussy`、`nude`（裸体）
- `masturbation`、`cum`、`orgasm`、`ejaculation`（性活动）
- `nipples`、`pussy_juice`、`sex_from_behind`、`female_ejaculation`（身体部位和行为）

用户可以通过高级过滤选项自定义需要过滤的标签。

### 阈值说明
- **0.4 - 非常严格**（默认）：最严格过滤，适合公开场合
- **0.5 - 严格**：较严格过滤
- **0.6 - 默认**：平衡模式
- **0.7 - 宽松**：较宽松过滤
- **0.8 - 非常宽松**：最宽松过滤

## 智能下载机制

当启用审核时，程序会：
1. 预估过滤率，初始下载目标数量的 2 倍
2. 审核下载的图片
3. 如果保留数量不足，根据实际过滤率继续下载
4. 重复直到达到目标数量（最多 5 轮）

**示例**：
- 目标：20 张图片
- 第 1 轮：下载 40 个作品 → 审核保留 15 张
- 第 2 轮：继续下载 10 个作品 → 审核保留 5 张
- 最终：保留 20 张图片 ✓

## 注意事项

1. **首次运行**：会自动下载 DeepDanbooru 模型（约 600MB），请耐心等待
2. **Token 有效期**：Pixiv Token 会过期，需要定期重新获取
3. **网络要求**：需要能够访问 Pixiv 服务器
4. **存储空间**：确保有足够空间存储下载的图片和模型文件

## 常见问题

### Q: 登录失败怎么办？
A: 检查 Token 是否正确，或重新获取 Token。

### Q: 下载速度慢？
A: Pixiv 服务器在日本，国内访问可能较慢。建议使用代理。

### Q: 审核太严格/太宽松？
A: 在"审核设置"中调整检测阈值。

### Q: 如何查看被过滤的图片？
A: 在 `downloads/[关键词]/ban/` 目录中查看。
